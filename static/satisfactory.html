How to join the GamezNET Satisfactory server

The server runs mods, so your game needs two things from the modding community: the Satisfactory Mod Manager app, and the Satisfactory Mod Loader mod installed with it. That's all: the GamezNET mod that powers this page runs on the server only.

PC only (Steam or Epic). Consoles and unmodded games can't join a modded server.

  1. Connect to GamezNET

    The server is on the GamezNET network. Open the GamezNET app and make sure you're Connected.

  2. Download Satisfactory Mod Manager (the app)

    Go to ficsit.app, the official Satisfactory modding site, and click Download the Mod Manager (A). Or use this button, which downloads the same file:

    Download Satisfactory Mod Manager

    Run the downloaded SatisfactoryModManager-Setup.exe and start Satisfactory Mod Manager.

  3. Install Satisfactory Mod Loader (the mod)

    1. Check the game install at the top left (B) is the one you play: Steam or Epic.
    2. Click Search mods (C) and type Satisfactory Mod Loader.
    3. It's the one by Satisfactory Modding with the SML logo (D).
    4. Click the install icon on the right of its row. When it's installed the icon turns green (E).
    5. Make sure Mods on is selected (F).

    That's the only mod you need: the server's own GamezNET mod runs on the server, not your PC. Other mods can stop you joining if the server doesn't have them, so leave them off unless they're cosmetic, client-only mods.

  4. Start Satisfactory

    Click Play Satisfactory (G), bottom left. Starting the game the usual way works too: mods stay on until you switch them off in Satisfactory Mod Manager.

  5. Join the server

    In Server Manager, add the server:

    Address 192.168.30.58 Port 7781

If it doesn't work

"Cannot connect to a modded server on a vanilla game client"
Your game is starting without mods. Check that Satisfactory Mod Loader is installed and Mods on is selected (step 3).
"This server is running Satisfactory Mod Loader, and your client doesn't have it installed"
Same fix: install Satisfactory Mod Loader and turn mods on.
A message about missing mods or an SML version
Your Satisfactory Mod Loader version doesn't match the server's (3.12.1). Update it in Satisfactory Mod Manager; if yours is newer than the server's, ask Nate to update the server. If it lists another mod, turn that mod off.
The server doesn't show up or times out
GamezNET isn't connected (step 1), or the server is restarting: check the status at the top of this page.
Playing without mods again
Switch mods Off in Satisfactory Mod Manager. Single-player and other servers work as normal either way.
